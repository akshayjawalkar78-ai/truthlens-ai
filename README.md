# Truthoganda — Propaganda & Rhetorical Manipulation Engine
> *"Forensic analysis of propaganda & coercive rhetoric."*

**Truthoganda** is an analytical platform dedicated exclusively to the deconstruction of propaganda techniques, fear appeals, loaded language, scapegoating, manufactured binaries, and coercive rhetoric in political and commercial discourse.

---

## 🏛️ Forensic Architecture & Methodology

Unlike general fact-checkers, Truthoganda focuses purely on **rhetorical mechanics and psychological coercion**:
- **Fear Appeals & Catastrophizing:** Identifying high-stakes survival urgency and domino-theory panic used to short-circuit dispassionate scrutiny.
- **Loaded Language & Demonization:** Mapping morally weaponized characterizations designed to induce visceral disgust or contempt.
- **Us vs. Them Polarization (Othering / Scapegoating):** Detecting predatory binary divisions between pure in-groups and hostile out-groups.
- **Manufactured Binaries & False Dilemmas:** Uncovering artificial all-or-nothing ultimatums that eliminate legitimate middle ground.
- **Cherry-Picked Data & Baseline Suppression:** Revealing misleading percentage spikes cited without underlying absolute denominators or baseline contexts.
- **Conspiratorial Framing:** Exposing narratives that explain routine systemic friction as the work of shadowy orchestrators.
- **Ad Hominem Discrediting:** Spotting personal vilification used to deflect from substantive policy data.

## 🎨 Editorial Design Constraints

Truthoganda strictly departs from generic AI dashboard templates:
- **No Floating Hero Cards:** Asymmetric editorial grid pairing analytical framing directly with the text inspector.
- **Restrained Editorial Palette:** Deep charcoal typography (`#1c1917`), warm unbleached paper background (`#fcfbf9`), and a single deep crimson brand accent (`#991b1b`). Zero purple gradients, neon glows, or decorative blobs.
- **Typographic Hierarchy:** Crimson Pro serif for headlines and dossier quotes; IBM Plex Sans / system monospace for data inspection.
- **Zero Pill Badge Clutter:** Clear section demarcations and contextual typography replacing generic eyebrow badges.

## 🚀 Running the Project

### Prerequisites
- Node.js (v18+)
- npm

### 1. Install Dependencies
```bash
npm install
```

### 2. Optional: Configure Live LLM Analysis
Truthoganda includes a full **JavaScript heuristic propaganda engine** that runs locally and offline. For deeper live semantic audits:
```bash
cp .env.example .env.local
```
Add your Gemini or OpenAI API key:
```env
GEMINI_API_KEY=your_key_here
```

### 3. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000)

### 4. Production Build
```bash
npm run build
npm start
```
